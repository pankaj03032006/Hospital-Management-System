# HOSPITAL MANAGEMENT SYSTEM

This is a Hospital Management System built using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). It is a web-based application designed to help hospitals efficiently manage patients, doctors, appointments, billing processes, and pharmacy inventory through a centralized platform.

## Features
User Authentication and Authorization – Secure login and role-based access control for administrators, doctors, receptionists, and other staff members.
User Management – Add, update, view, and delete user accounts.
Patient Management – Maintain patient records, medical histories, and personal information.
Doctor Management – Manage doctor profiles, specialties, schedules, and availability.
Appointment Scheduling – Book, reschedule, and cancel patient appointments efficiently.
Billing and Payment Management – Generate invoices, track payments, and manage billing records.
Medicine Availability Management – Monitor pharmacy inventory by adding, updating, and tracking medicine stock levels, availability status, and low-stock alerts to ensure timely access to medications.
Dashboard and Analytics – Interactive dashboard displaying key performance indicators (KPIs), patient statistics, appointment trends, and other hospital insights for informed decision-making.
Tech Stack
Frontend: React.js, HTML5, CSS3, JavaScript, Material UI
Backend: Node.js, Express.js
Database: MongoDB
Authentication: JWT (JSON Web Tokens)
Version Control: Git & GitHub
